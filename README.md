um jogo de escolha (game choice) em que você tenta sobreviver 1 noite no minecraft

---
## 📚 Aprendizados
-jogo estilo "escolha sua aventura"
-fundamentos java script
- Event Listeners, botões, funções e condicionais
- Trabalho em Equipe

## ⚙️ Funcionalidades
- Clique no botão de acordo com a sua escolha
- Cada botão leva para uma trilha da história
- Cada trilha tem um desfecho diferente

## 🛠️ Stack


- JavaScript
- HTML5
- CSS3

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/dangamerbloxyt/Surviving-a-night-in-a-Minecraft-
```

2. Abra o arquivo `index.html` em seu navegador.
